# 日本株 銘柄発表 MVP

手入力の数値と根拠を、銘柄ごとのSQLiteプロジェクトとして管理するローカルWebアプリです。

## 起動方法（Windows）

1. Python 3.10以降をインストールします。
2. `run_windows.bat` をダブルクリックします。
3. 初回は必要なパッケージがインストールされ、ブラウザでアプリが開きます。

コマンドから起動する場合は、プロジェクトフォルダで次を実行します。

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## PC・スマホ表示

画面は端末のUser-Agentを使って自動判定します。PCでは年度を横に並べたモデル表、iPhone・Androidでは年度を1つ選ぶ縦型のPL・セグメント表を表示します。サイドバーの「表示モード」で「自動／スマホ／PC」を手動で切り替えることもできます。

同じWi-Fi内のiPhoneから利用する場合は、PCでアプリを起動したまま、起動時に表示される `Network URL`（例：`http://192.168.0.92:8501`）をSafariで開きます。PCの電源が切れている場合や、別のWi-Fi・モバイル回線からは接続できません。

## 機能

- 銘柄プロジェクトの新規作成・選択・保存・削除
- PL・業績予想（実績・会社予想・自分予想、詳細PL、利益率、前年比、EPS）の横並び編集・保存
- 銘柄コードまたは会社名（部分一致候補）から企業を検索
- 公式の本決算短信PDFから、直近3年の通期連結PLと報告セグメントを1回の取得操作で自動反映
- セグメント売上高・利益・契約社数・平均単価などを年度横並びで比較
- 企業周辺ニュース、技術進化、法令・制度・業界ルール、PL・セグメントからのカタリスト候補提案と、弱気・標準・強気の推定株価影響率
- 数量モデルまたは売上比率モデルによるカタリスト計算、根拠情報の保存、自分予想売上への反映
- 弱気・標準・強気のシナリオ分析による業績、EPS、目標株価、上昇余地の試算

PLとカタリストの金額単位は百万円、発行済株式数・平均株式数は百万株、EPS・株価は円、時価総額は億円です。率は％表記で入力します（20% は `20`）。データベースは初回起動時に同フォルダの `stock_projects.db` として作成されます。旧バージョンのデータベースがある場合は、単位変換の前に同フォルダへバックアップを作成します。

会社予想と自分予想は同じ年度にも別々の列として保存できます。会社が開示していない予想項目は空欄のまま保存され、0には変換されません。カタリスト画面の「保存して自分予想へ反映」を押すと、同年度の会社予想売上（なければ最新実績）に追加売上を加え、自分予想の売上高へ反映します。利益など根拠のない項目は自動補完しません。

実績PLは原則として直近3期を表示し、会社予想・自分予想は別列で残します。公式IRがIRPocketで配信される企業にも対応し、決算短信で実績PL、決算説明資料で事業別・サービス別売上を補完します。資料に明示されない値は推測しません。

カタリスト候補は企業周辺の公開ニュース、技術進化、法令・制度・業界ルール、保存済みの最新実績、セグメント売上、事業内容・強みから生成します。候補ごとに弱気・標準・強気の推定株価影響率を表示します。計算は「追加売上×増分営業利益率×（1－税率）÷株式数×PER÷現在株価」で、追加売上と前提は計算根拠として確認・修正できます。これは試算であり将来の株価を保証するものではありません。

## テスト

```powershell
python -m pytest -q
```

計算（EPS、営業利益率、売上成長率、追加売上、目標株価）とSQLiteへの保存・読込をテストします。

## J-Quants API V2（任意）

企業データ取得を使う場合だけ、J-QuantsのAPIキーを次のどちらかで設定してください。APIキーはソースコードとSQLiteには保存しません。

```powershell
$env:JQUANTS_API_KEY = "発行したAPIキー"
python -m streamlit run app.py
```

または、プロジェクト直下の `.streamlit/secrets.toml` に次を保存します。

```toml
JQUANTS_API_KEY = "発行したAPIキー"
```

会社概要画面の「企業データ取得」で証券コード（4桁・5桁）または会社名を検索し、候補を選んで「データを取得」を押します。プレビューで現在値とAPI取得値を比較し、項目ごとのチェックを選んで「選択したデータを反映」を押したときだけ保存されます。投資仮説、カタリスト、リスクなどの手入力テキストはAPI反映の対象外です。

## 無料公開データ（標準）

- JPXの東証上場銘柄一覧を標準の企業マスターとして使用します。初回取得後は `data_cache/` に保存し、7日間は再利用します。「JPX企業マスター更新」で明示的に更新できます。通信に失敗した場合は前回キャッシュを使い、キャッシュがない場合でも手入力は利用できます。
- EDINET API Version 2は有価証券報告書のXBRL取得に使用できます。EDINETの無料利用登録で発行したキーを、`EDINET_API_KEY` として環境変数または `.streamlit/secrets.toml` に設定してください。キーは保存されません。
- 企業公式IRページの本決算短信をローカルキャッシュへ保存し、`pypdf` と `pdfplumber` で文字・罫線・表の配置を解析します。連結PL、報告セグメント、会社固有KPIのうち資料で確認できた数値だけを反映します。

```toml
EDINET_API_KEY = "発行したAPIキー"
```

標準構成では現在株価は手入力です。株価基準日・入力元・手入力/自動取得の区別を記録し、J-Quantsによる株価取得は任意機能として利用できます。

## 公式IR資料からPL・セグメントを作る

会社概要に保存した銘柄コードと会社名から公式IRを自動探索します。PL画面の「PL情報を取得」またはセグメント画面の「セグメント情報を取得」を押すと、第1～第3四半期・中間期を除外し、発表済み通期実績の直近3年だけを表へ反映します。単一セグメントと明記された企業は、全社PLをその事業セグメントとして表示します。

- 売上高、売上原価、売上総利益、販管費
- 営業利益、営業外収益・費用、経常利益
- 特別利益・損失、税引前利益、法人税等、親会社株主に帰属する当期純利益
- 平均株式数、EPS、各利益率、前年比
- 報告セグメント別の外部顧客売上高、セグメント利益
- 契約社数、店舗数、利用者数、平均単価など資料に明示された会社固有KPI

PDFはローカルにキャッシュされ、同じURLは「その他」のキャッシュ更新を選ぶまで再ダウンロードしません。「その他」からPDFを複数アップロードする方法も利用できます。資料にない値は推測せず、空欄のまま手入力できます。

## OpenAIによるPDF補助解析（任意）

通常のPython解析でPLの詳細行やセグメントを取得できなかった場合だけ、OpenAI Responses APIへ公開決算PDFを送り、構造化データとして補助抽出できます。これは完全な任意機能で、初期状態ではオフです。無料で使う場合は設定不要で、公式PDF解析、EDINET XBRL、J-Quants、手入力を利用できます。

ローカルでは環境変数、公開版ではStreamlit Community CloudのSecretsへ次を設定してください。APIキーはソースコードやSQLiteへ保存されません。

```toml
OPENAI_API_KEY = "発行したOpenAI APIキー"
# 任意。未指定時はコスト重視のモデルを使用します。
OPENAI_FINANCIAL_MODEL = "gpt-5.6-luna"
```

処理順は「無料のPDF表解析 → EDINET XBRL/J-Quants等の構造化データ」です。画面の「その他」で「有料のOpenAI補助を使う」を明示的にオンにした取得だけAIを使います。AIには推測禁止、連結優先、通期累計、出典ページ必須を指示し、返却形式をJSON Schemaで制限しています。それでも誤抽出の可能性はあるため、画面に表示される資料名・ページ番号と原文を照合してください。OpenAI APIをオンにした場合だけAPI料金が発生します。

- [OpenAI API quickstart](https://developers.openai.com/api/docs/quickstart)
- [OpenAI API file inputs](https://developers.openai.com/api/docs/guides/file-inputs)
- [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)

PL候補はCSVまたはExcelでダウンロードできます。Excel出力には `openpyxl`、PDFテキスト抽出には `pypdf` が必要です。

## 制約

- 公式IRページを自動特定できない銘柄では、決算短信PDFのアップロードまたは手入力を利用します。
- 会社独自レイアウト、画像PDF、セグメント非開示企業では自動抽出できない場合があります。
- AI補助解析は任意です。APIキー未設定、利用上限、特殊なPDFでは取得できないため、空欄を手入力してください。

## 外出先から利用するための公開

コードはGitHubの非公開リポジトリへ保存し、Streamlit Community Cloudから`app.py`を起動します。APIキーはGitHubへ保存せず、StreamlitのSecrets画面で`JQUANTS_API_KEY`や`EDINET_API_KEY`を設定してください。

ローカル版の`stock_projects.db`はGitHubへアップロードしません。Streamlit Community Cloudのローカルファイルは永続保存先として保証されないため、継続運用する公開版ではSQLiteの代わりにクラウドDBを設定します。クラウドDBの設定が完了するまでは、公開版で入力したデータが再起動時に消える可能性があります。
